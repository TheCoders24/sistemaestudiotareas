- Un archivo por bloque de trabajo relevante (`informe-<tema>-<version|fecha>.md`).
- El informe detalla el problema, la causa, los archivos modificados, la verificación y el resultado, paso a paso.
- Los hashes de commit permiten rastrear cada cambio con `git show <hash>`.
